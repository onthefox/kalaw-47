# Архив документации

Документы здесь устарели и сохранены только для истории проекта. Они описывают
состояние калав-47 на момент планирования (Q2–Q3 2026) и не отражают текущую
архитектуру.

## Почему заархивированы

| Документ | Причина архивации |
| --- | --- |
| `IMPROVEMENTS.md` | Анализ пробелов; перечисленные пробелы (поиск, экспорт, пагинация, UI) уже закрыты |
| `PERFORMANCE_SUMMARY.md` | Ссылается на удалённые React-файлы `ui/mind_palace/src/App.jsx`, `Graph.jsx` |
| `PROGRESS_SUMMARY.md` | Снимок августа 2026: эпоха 17 тестов, React-UI, Q3-планирование |
| `ROADMAP.md` | Q3-этап «агенты» помечен как «0% planned» — фактически поставлен в релизе |
| `ROADMAP_IMPROVED.md` | Ранняя редакция роадмапа, заменена текущим состоянием проекта |
| `STORIES.md` | Черновые пользовательские истории до финальной спецификации интентов |
| `TASK_LIST.md` | Чек-лист задач, выполненный и неактуальный |
| `USE_CASES.md` | Ранние сценарии использования; актуальный сценарий — `docs/DEMO.md` |

## Актуальная документация

- `README.md` — обзор проекта и быстрый старт
- `docs/DEMO.md` — сценарий демонстрации текущего UI
- `docs/RELEASE_SUMMARY.md` — итоговая сводка релиза
- `CONTRIBUTING.md`, `SECURITY.md` — процессы

Папка `meta/` упразднена; больше не используйте пути `meta/revolution/*`.
